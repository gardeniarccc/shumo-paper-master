# 数模论文大师

> 基于近五年国赛 C 题国家级一等奖论文范式 · 一等奖教练实战经验提炼 · 全流程标准化写作工具包

## 项目简介

本项目是面向全国大学生数学建模竞赛（C 题数据建模类）的论文写作标准化工具包。深度拆解近 5 年 C 题国一优秀论文的写作逻辑、结构范式与评分偏好，结合一等奖带队教练的实战经验与国赛评审规则，沉淀为可直接调用的技能文件（SKILL.md）、章节标准库、写作模板库与质量校验清单，帮助参赛团队快速产出符合国奖评审标准、具备冲奖实力的高质量论文。

## 核心能力

### 1. 国一范式精准对齐
严格对标近 5 年 C 题国家级获奖论文的章节结构、论证密度、公式排版、图表风格与篇幅占比，复用经过评审验证的专业表述与逻辑衔接方式。

### 2. 全章节写作规范
覆盖摘要、问题重述、模型假设、数据预处理、模型建立与求解、结果检验、灵敏度分析、模型评价、参考文献、附录全流程，每章节明确写作标准与得分要点。

### 3. 技术细节自动补全
- 数据处理：补充清洗逻辑、异常值处理依据、特征工程方法
- 模型算法：明确参数设置、求解工具、迭代条件、数据集划分
- 数学推导：补全关键推导步骤，杜绝黑箱表述与逻辑跳跃

### 4. 数学逻辑严格执行
- 所有模型输出完整数学表达式，按章节规范编号
- 符号全局统一定义，前后完全一致
- 目标函数、约束条件、求解过程逻辑链条完整闭环

### 5. 反 AI 幻觉机制
- 禁止无依据空泛结论，所有论断必须有数据或模型结果支撑
- 禁止盲目堆砌复杂模型，每个选型必须说明对比依据
- 禁止编造数据、参数与实验结果，全程可复现
- 禁用「不难看出」「综上所述」等 AI 高频套话

### 6. 缺失内容智能提醒
按照国一论文标准自动检测内容完整度，明确提示需补充的数据、图表、分析模块与验证环节，对标范文给出补充方向。

### 7. 低 AIGC 化学术文风
采用客观凝练的第三人称学术书面语，规避 AI 式长句堆砌与冗余修饰，句式节奏匹配真实获奖论文。

## 使用方法

1. 克隆或下载本仓库，解压工具包
2. 将 `SKILL.md` 安装为可调用的技能文件（或按其中指令手动执行）
3. 加载 `references/c_paper_exemplars.md` 获取近五年 C 题优秀论文范式
4. 按 `templates/` 中各章节模板逐步完成论文撰写
5. 完成后使用 `references/quality_checklist.md` 完成终稿质量校验

## 国赛获奖核心逻辑

### 评委评分层级
- **摘要定档次**：30 秒读完直接决定论文档位，是冲奖的核心
- **模型定分数**：模型适配性、推导严谨性、结果可信度决定最终分数区间
- **细节定成败**：格式规范、图表质量、分析完整性决定是否冲击国一
- **创新定区分**：方法融合、视角改进是国一的核心区分度

### C 题专属得分铁则
- 数据优先：处理步骤透明可复现，来源、清洗、特征工程全程有依据
- 适配为王：模型选对不选难，每个模型必须说明选型理由
- 结果量化：所有结论配数值指标与误差分析，不用空泛表述
- 分析闭环：必须包含「结果检验 + 灵敏度分析 + 模型优缺点」完整三部曲

## 注意事项
