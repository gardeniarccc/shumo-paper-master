```
  → 收敛条件
  → 实现工具/库/版本

X.X.4 结果呈现
  → 结果表格（三线表）
  → 结果可视化图
  → （可选）中间过程图

X.X.5 结果分析
  → 结果说明了什么？
  → 有什么规律？
  → 是否符合预期？为什么？

  → 误差分析（量化误差+来源）
  → （加分）与其他方法对比
```

#### X.X.3 评价方法

##### X.X.3.1 指标预处理

**正向化处理**：对成本型指标取倒数，对适度型指标按以下公式转化：
$$ x'_{ij} = \frac{1}{1 + |x_{ij} - x^*|} $$

其中 $x^*$ 为最优值。

**标准化处理**：采用极差标准化消除量纲影响：
$$ r_{ij} = \frac{x'_{ij} - \min_j x'_{ij}}{\max_j x'_{ij} - \min_j x'_{ij}}} $$

##### X.X.3.2 权重确定

采用熵权法确定各指标的客观权重。熵权法的基本原理是根据指标数据的离散程度赋权，差异越大的指标信息量越多、权重越大。

计算步骤：
1. 计算第 $i$ 个方案在第 $j$ 个指标下的比重：$p_{ij} = r_{ij} / \sum_{i=1}^{m} r_{ij}$
2. 计算第 $j$ 个指标的熵值：$e_j = -k \sum_{i=1}^{m} p_{ij} \ln p_{ij}$，其中 $k = 1/\ln m$
3. 计算第 $j$ 个指标的权重：$w_j = (1-e_j) / \sum_{j=1}^{n} (1-e_j)$

各指标权重计算结果见表X-X。

##### X.X.3.3 综合评价（TOPSIS）

采用TOPSIS方法进行综合评价。通过计算各方案与正理想解和负理想解的相对贴近度进行排序。

正理想解：$V^+ = \{\max v_{ij}\}$（效益型指标）
负理想解：$V^- = \{\min v_{ij}\}$（效益型指标）

各方案到正理想解距离：$D_i^+ = \sqrt{\sum_{j=1}^{n} (v_{ij} - v_j^+)^2}$
各方案到负理想解距离：$D_i^- = \sqrt{\sum_{j=1}^{n} (v_{ij} - v_j^-)^2}$

相对贴近度：$C_i = D_i^- / (D_i^+ + D_i^-)$

## 各方法的选型理由库

写作"为什么选这个方法"时，可从以下维度组合：

| 方法 | 选它的理由 | 不选其他方法的理由 |
|------|-----------|-------------------|
| 线性规划 | 问题是线性的，有精确最优解，求解快 | 精确算法无法处理非线性部分 |
| 遗传算法 | 全局搜索能力强，不依赖梯度，适合非线性/组合优化 | 计算耗时比精确算法长 |
| 熵权TOPSIS | 客观赋权，避免主观偏差，计算简单直观 | 不考虑指标间的相互影响 |
| 随机森林 | 无需假设数据分布，能捕捉非线性关系，有特征重要性 | 可解释性不如线性模型 |
| XGBoost/LightGBM | 预测精度高，处理类别不平衡好，效率高 | 超参数调优较复杂 |
| K-Means | 简单高效，适合大规模数据聚类 | 需要预先指定k值，对初始值敏感 |
| ARIMA | 统计理论完善，有明确的显著性检验 | 只适合线性平稳序列 |
| LSTM | 能捕捉长期依赖关系，适合非线性时序 | 需要大量数据，可解释性差 |
| 混合效应模型 | 处理层次/纵向数据，考虑个体异质性 | 假设比普通回归复杂 |
| 蒙特卡洛模拟 | 不需要解析解，适用范围广，直观易懂 | 计算量大，精度受抽样数限制 |
