# 数据处理章节写作模板

> 数据处理是C题的"基本功展示"环节。处理流程透明可复现、有依据、有描述性分析，是拿高分的基础。

---

## 标准结构

```
3 数据预处理与描述性分析

3.1 数据来源与说明
  → 数据从哪来？
  → 包含哪些表/哪些变量？
  → 数据规模（多少行、多少列）

3.2 数据清洗
  3.2.1 缺失值处理
    → 缺失情况统计（每列缺失率）
    → 处理策略（分情况处理）
    → 处理依据（为什么用这种方法）
    → 处理结果（完整率提升到多少）

  3.2.2 异常值处理
    → 检测方法（3σ/IQR/DBSCAN/箱线图）
    → 判定依据（为什么用这个方法检测）
    → 检测结果（多少条异常、占比）
    → 处理方式（删除/修正/保留+原因）

  3.2.3 数据标准化/归一化
    → 方法选择（Min-Max/Z-score/对数）
    → 选择依据
    → 处理公式

3.3 描述性统计分析
  → 各变量的均值、标准差、极值、分位数
  → 描述性统计表
  → 分布特征分析

3.4 相关性分析
  → 方法选择（Pearson/Spearman）
  → 相关性热力图
  → 关键相关关系解读

3.5 （可选）特征工程
  → 构造了哪些衍生特征
  → 构造方法和依据
```

### 3.2 数据清洗

原始数据存在一定的缺失、异常和量纲不一致问题，需进行预处理以保证后续建模的可靠性。

**表3-1 各变量缺失率统计**

| 变量 | 非缺失值数量 | 缺失值数量 | 缺失率 |
|------|------------|-----------|--------|
| 变量1 | XX | XX | X.X% |
| 变量2 | XX | XX | X.X% |
| ... | ... | ... | ... |

针对不同缺失程度的变量，采用差异化处理策略：

- **缺失率 < 5%**：采用均值/中位数插补。由于缺失比例很小，简单插补对整体分布影响可忽略。
- **缺失率 5%-20%**：采用XX插补（如KNN插补/回归插补/线性插值）。该方法能够利用其他变量的信息进行更准确的估计，适用于中等缺失程度。
- **缺失率 > 20%**：予以删除。缺失比例过高时，插补的可靠性大幅下降，删除该变量是更稳妥的选择。

对于时间序列型数据，采用线性插值法填补缺失值，依据是相邻时间点的数据具有连续性和相关性。

处理后数据完整率由XX%提升至XX%。

#### 3.2.2 异常值处理

采用3σ原则检测异常值。对于近似服从正态分布的变量（通过直方图和Shapiro-Wilk检验初步验证），以均值±3倍标准差为判异标准，超出该范围的数据点判定为异常值。

对于不服从正态分布的变量，采用IQR（四分位距）法则：以 $Q_1 - 1.5 \times IQR$ 和 $Q_3 + 1.5 \times IQR$ 为上下界，超出范围判定为异常值。

各变量的异常值检测结果见表3-2。

**表3-2 异常值检测结果**

| 变量 | 异常值数量 | 占比 | 检测方法 |
|------|-----------|------|---------|
| 变量1 | XX | X.X% | 3σ原则 |
| 变量2 | XX | X.X% | IQR法则 |
| ... | ... | ... | ... |

对检测出的异常值，处理方式如下：
- 确认为录入错误的异常值：予以修正（替换为相邻均值/中位数）
- 真实存在但极端的值（如XX）：予以保留，在建模时采用对异常值鲁棒的方法（如中位数、树模型）
- 明显错误且无法修正的：予以删除

最终共处理异常值XX条，占总样本的X.X%。

#### 3.2.3 数据标准化

由于各指标的量纲和数量级差异较大，为消除量纲影响、便于后续建模计算，对数据进行标准化处理。

本文采用Z-score标准化方法：
$$ x' = \frac{x - \mu}{\sigma} $$

其中 $\mu$ 为变量的均值，$\sigma$ 为变量的标准差。标准化后各变量的均值为0，标准差为1。

选择Z-score标准化的依据是：多数后续建模方法（如线性回归、SVM、PCA等）假设数据服从正态分布或对数据尺度敏感，Z-score标准化与这些方法的适配性更好。

### 3.5 特征工程

在原始数据基础上，结合领域知识，构造以下衍生特征：

**（1）时间特征**
- 对于时间序列数据，提取年份、月份、季度、星期几、是否节假日等时间特征；
- 构造滞后特征（lag-1, lag-7, lag-30等）和滑动统计特征（滑动均值、滑动标准差）。

**（2）比例/比率特征**
- 构造XX率、XX占比、XX/XX比值等比例特征；
- 依据：相对值往往比绝对值更能反映事物的本质。

**（3）交互特征**
- 构造XX与XX的乘积/比值项，捕捉变量间的交互效应；
- 依据：根据相关性分析和领域知识，XX与XX可能存在交互作用。

**（4）分箱/离散特征**
- 将连续变量按业务含义/分位数进行分箱，构造等级变量；
- 依据：某些关系是非线性的，分箱后能更好地捕捉。

最终用于建模的特征共XX个。

## 各方法的依据话术库

写"为什么用这个处理方法"时直接套用：

| 处理步骤 | 方法 | 依据话术 |
|---------|------|---------|
| 缺失值 | 均值插补 | 缺失率低(<5%)，简单插补对整体分布影响小 |
| 缺失值 | 中位数插补 | 变量存在偏态，中位数对极端值更鲁棒 |
| 缺失值 | 线性插值 | 时间序列数据，相邻时间点具有连续性 |
| 缺失值 | KNN插补 | 利用其他变量的相似样本信息，精度更高 |
| 缺失值 | 删除变量 | 缺失率过高(>20%)，插补可靠性不足 |
| 异常值 | 3σ原则 | 变量近似服从正态分布，3σ外概率仅0.27% |
| 异常值 | IQR法则 | 变量不服从正态分布，IQR对分布无假设 |
| 异常值 | DBSCAN | 高维数据，利用密度聚类检测局部异常 |
| 标准化 | Z-score | 后续建模方法对数据尺度敏感，如SVM/PCA/回归 |
| 标准化 | Min-Max | 需要将数据压缩到[0,1]区间，如神经网络/权重计算 |
| 标准化 | 对数变换 | 数据高度右偏，取对数后近似正态 |
| 相关性 | Pearson | 数据近似二元正态分布，需度量线性相关程度 |
| 相关性 | Spearman | 数据为序数/不服从正态分布，需度量单调相关关系 |
| 相关性 | 互信息 | 捕捉非线性相关，适用于复杂关系的初步探索 |

## 避坑提醒

### ❌ 坑1：数据处理太简单
> "数据经过清洗后用于建模。"

一句话带过数据处理，评委怎么知道你会不会做数据？

### ❌ 坑2：描述性统计只有表没有分析
列了一大堆统计量，然后一句话不说。统计量是给分析服务的，不能只是罗列。

### ❌ 坑3：相关性分析发现了问题不处理
热力图画得挺漂亮，发现变量间高度相关（多重共线性），然后后面建回归模型时完全不处理。

→ 正确做法：发现问题 → 在建模时做对应处理（如用正则化/PCA/选代表性变量），前后呼应。

### ❌ 坑4：特征工程凭空构造
构造了一堆特征，不说为什么要构造这些特征、依据是什么。

→ 正确做法：每个构造的特征都要有领域依据或统计依据。
