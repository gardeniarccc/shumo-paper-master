# 参考文献格式模板

> 严格遵循 GB/T 7714-2015 格式。每篇文献必须在正文引用，引用位置必须合理。

---

## 一、格式速查

### 1. 期刊论文 [J]

```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

**示例**：
```
[1] 张三, 李四, 王五. 基于XX算法的XX优化研究[J]. 系统工程理论与实践, 2023, 43(5): 1234-1245.
[2] Smith J, Johnson A, Williams B. A novel approach to XXX optimization[J]. European Journal of Operational Research, 2022, 298(3): 876-890.
```

### 2. 专著 [M]

```
[序号] 作者. 书名[M]. 版本(第1版不注). 出版地: 出版社, 出版年: 起止页码.
```

**示例**：
```
[3] 姜启源, 谢金星, 叶俊. 数学模型[M]. 5版. 北京: 高等教育出版社, 2018: 45-67.
[4] Winston W L. Operations Research: Applications and Algorithms[M]. 4th ed. Belmont: Brooks/Cole, 2004: 210-235.
```

### 3. 学位论文 [D]

```
[序号] 作者. 题名[D]. 保存地点: 保存单位, 年份.
```

**示例**：
```
[5] 赵六. 基于XX方法的XX决策模型研究[D]. 北京: 清华大学, 2022.
```

### 4. 会议论文集 [C]

```
[序号] 作者. 题名[C]//会议名称, 会议地点, 会议时间. 出版地: 出版者, 出版年: 起止页码.
```

**示例**：
```
[6] Chen X, Wang Y. XX optimization using XX algorithm[C]//Proceedings of the 15th International Conference on XX, Shanghai, 2022. New York: IEEE, 2022: 345-351.
```

### 5. 标准 [S]

```
[序号] 发布单位. 标准编号 标准名称[S]. 发布年.
```

**示例**：
```
[7] 国家市场监督管理总局. GB/T 7714-2015 信息与文献 参考文献著录规则[S]. 2015.
```

### 6. 报告 [R]

```
[序号] 机构. 报告名称[R]. 地点: 机构, 年份.
```

**示例**：
```
[8] 国家统计局. 中国统计年鉴2024[R]. 北京: 中国统计出版社, 2024.
```

### 7. 电子文献 [EB/OL]

```
[序号] 作者. 题名[EB/OL]. (发表日期)[引用日期]. URL.
```

**示例**：
```
[9] 中国科学院. XX研究报告[EB/OL]. (2023-06-15)[2024-08-20]. https://xxx.xxx.xxx/report.pdf.
```

## 三、正文中引用的几种方式

### 1. 方法引用（最常用）
- "本文采用XX方法[1]对XX进行建模。"
- "参考XX的研究[3]，建立XX模型。"
- "XX算法由XX等人提出[5]，其基本思想是XX。"

### 2. 数据/事实引用
- "根据XX统计[8]，XX。"
- "已有研究表明[14]，XX现象普遍存在。"

### 3. 对比引用
- "这一结果与XX的研究结论[12]一致。"
- "与XX的结果相比[20]，本文方法在XX指标上提升了XX%。"

### 4. 理论依据引用
- "根据XX定理[2]，XX。"
- "依据GB/T 7714-2015标准[7]，XX。"

## 四、常见格式错误

### ❌ 错误1：作者名格式不对
- 中文：作者超过3人时，列出前3人，后加"等"
  ✅ "张三, 李四, 王五, 等."
- 英文：姓在前（全拼），名在后（首字母缩写）
  ✅ "Smith J, Johnson A B."

### ❌ 错误2：期刊名缩写不统一
有的全称、有的缩写。要么都全称，要么都缩写，统一即可。

### ❌ 错误3：标点符号混乱
中英文标点混用。注意：中文文献用中文标点，英文文献用英文标点。

### ❌ 错误4：卷期号缺失
期刊论文漏了卷号或期号。能查到的一定要补上。

### ❌ 错误5：正文无引用
列了参考文献，正文一次都没引用。必须确保每篇文献在正文都有引用。

### ❌ 错误6：顺序不对应
正文引用[1][2][3]，参考文献列表里的顺序和正文出现的顺序不一致。

GB/T 7714 顺序编码制：参考文献按正文首次引用的顺序排列。

## 五、数量建议

| 论文水平 | 参考文献数量 | 质量要求 |
|---------|------------|---------|
| 省三 | 5-8篇 | 有就行 |
| 省二 | 8-10篇 | 格式基本正确 |
| 省一 | 10-12篇 | 格式正确，有相关论文 |
| 国奖 | 12-18篇 | 中英文结合，经典文献+近年论文，格式规范 |

不要为了凑数量乱加文献。每篇文献都要有实际引用，且和内容相关。
