## 三、常见避坑

### ❌ 灵敏度分析避坑

1. **不要只做1个参数**：至少2个，3个最佳。只做1个显得分析不够深入。
2. **不要变化范围太小**：±5%看不出什么，通常±20%比较合理。
3. **不要只列数字不分析**：列了表就完了？不对，要分析趋势、计算灵敏度系数、排序、给结论。
4. **不要选不重要的参数**：选那些真正重要、真正有不确定性的参数。选一个没影响的参数做分析，结果"很稳定"，有什么意义？
5. **不要只做单因素**：有时间可以加个双因素/多因素的联合分析（等高线图/响应面），是加分项。

### ❌ 模型评价避坑

1. **优点不要全是套话**：
   ❌ "模型具有科学性、合理性、创新性"
   ✅ "模型充分考虑了数据的层次结构，采用混合效应模型刻画个体异质性，ICC=0.743验证了个体差异的显著影响"

2. **缺点不要假大空**：
   ❌ "计算速度可以进一步提升"
   ✅ "模型假设误差服从正态分布，当实际分布偏态较大时，估计偏差可能增大"

3. **推广不要无限拔高**：
   ❌ "可广泛应用于各行各业"
   ✅ "可推广至具有类似层次结构的纵向数据分析问题，如XX和XX领域"

4. **优缺点数量要平衡**：
   不要写5条优点只写1条轻描淡写的缺点。优点2-4条，缺点2条，比例合适。

## 四、龙卷风图制作模板

```python
import matplotlib.pyplot as plt
import numpy as np

# 灵敏度数据
params = ['参数A', '参数B', '参数C', '参数D']
low_changes = [-8.2, -15.3, -3.1, -1.5]   # 各参数降20%时目标变化率
high_changes = [7.8, 16.2, 2.9, 1.8]      # 各参数升20%时目标变化率

# 按总影响排序
total_impact = [abs(l) + abs(h) for l, h in zip(low_changes, high_changes)]
sorted_idx = np.argsort(total_impact)
params = [params[i] for i in sorted_idx]
low_changes = [low_changes[i] for i in sorted_idx]
high_changes = [high_changes[i] for i in sorted_idx]

fig, ax = plt.subplots(figsize=(8, 4))

y = np.arange(len(params))
bar_height = 0.6

# 左侧（参数减小的影响）
ax.barh(y, low_changes, height=bar_height, color='#2E5A88', alpha=0.8, label='参数降低20%')
# 右侧（参数增大的影响）
ax.barh(y, high_changes, height=bar_height, color='#E8842B', alpha=0.8, label='参数升高20%')

# 中间基准线
ax.axvline(x=0, color='black', linewidth=0.8)

ax.set_yticks(y)
ax.set_yticklabels(params)
ax.set_xlabel('目标函数变化率 (%)')
ax.set_title('图X-X 各参数灵敏度龙卷风图', fontweight='bold')
ax.legend(loc='lower right')
ax.grid(True, alpha=0.3, axis='x', linestyle='--')

plt.tight_layout()
plt.savefig('sensitivity_tornado.png', dpi=300, bbox_inches='tight')
plt.close()
```
