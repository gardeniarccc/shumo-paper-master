# 摘要写作模板与范文对照

> 摘要是论文的门面，30秒定档次。四段式结构 + 量化结果 + 创新亮点 = 国一摘要。

---

## 四段式标准结构

```
第一段：背景与问题（1-2句，50-80字）
  问题是什么 → 为什么重要 → 有什么挑战

第二段：总体思路（1句，30-50字）
  本文以什么为研究对象，采用什么总体框架/思路

第三段：分问题方法与结果（每问1-2句，核心段）
  问题X + 方法 + 核心量化结果
  每问都要有方法名 + 数据

第四段：创新与价值（1-2句，40-60字）
  本文的创新点/亮点是什么 → 有什么价值/意义
```

## 摘要质量检查清单

写完摘要后，对照检查：

- [ ] **字数**：300-500字（3问350字左右，4问450字左右）
- [ ] **结构**：严格四段式
- [ ] **每个子问题都有：方法名 + 量化结果**
- [ ] **没有空话**：没有"效果良好""深入研究""重要意义"
- [ ] **有创新点**：最后一段明确说了本文的创新是什么
- [ ] **关键词精准**：3-5个，不是大词
- [ ] **自包含**：读完摘要就知道全文做了什么、用了什么、得到了什么，不需要看正文

## 避坑：常见摘要问题

### ❌ 问题1：只说方法不说结果
> "针对问题一，本文建立了线性规划模型。"

只说建了模型，没说得到了什么结果。评委怎么知道你做得好不好？

**改**："针对问题一，建立多约束线性规划模型，采用Gurobi求解，得到最优方案，目标值为XXX。"

### ❌ 问题2：结果无量化
> "结果表明模型效果很好。"

好到什么程度？没有数据。

**改**："模型在测试集上准确率达92.3%，较基线模型提升4.8个百分点。"

### ❌ 问题3：背景太长
背景写了两三行，占了摘要三分之一的篇幅。

**改**：背景1-2句即可，重点放在方法和结果上。

### ❌ 问题4：关键词是大词
> 关键词：数学建模；优化算法；数据分析

太泛了，等于没说。

**改**：关键词要精准到具体方法和问题域，如"种植优化；CVaR；差分进化遗传算法"。

### ❌ 问题5：口语化/不专业
> "我们用了好几种方法来解决这个问题。"

绝对不能出现。

## 写作顺序建议

不要先写摘要！正确顺序是：

1. 全文写完 → 2. 提炼每个问题的核心方法和结果 → 3. 写摘要 → 4. 反复修改压缩到规定字数

摘要是全文的浓缩，必须在所有内容都确定之后再写。写好后至少改3遍，每遍删减10%的废话。
