## 一、2021年·供应链优化型（3问）

**代表论文**：C066 / C085 / C169 / C283

### 结构特点
- 第一问：评价 + 优化 + 路径规划（三小问合一）
- 第二问：不确定性 / 鲁棒优化
- 第三问：扩展场景 / 紧急情况

### 章节节奏
```
1 问题重述
2 模型假设与符号说明
3 数据处理与分析
4 问题一：供应商评价与订购运输方案
  4.1 问题分析（为什么要先评价再规划再路径）
  4.2 供应商综合评价模型（熵权TOPSIS/AHP）
  4.3 多目标订购优化模型
  4.4 运输路径优化（GA-TSP/VRP）
  4.5 结果分析
5 问题二：不确定需求下的鲁棒优化
  5.1 问题分析
  5.2 随机场景生成（蒙特卡洛）
  5.3 鲁棒优化/CVaR模型
  5.4 结果与风险分析
6 问题三：紧急转运/多阶段动态优化
  6.1 问题分析
  6.2 两阶段/多阶段模型
  6.3 求解与结果
7 灵敏度分析
8 模型评价与推广
```

### 章节节奏
```

  5.2 K-Means聚类

  5.4 最佳聚类数确定（轮廓系数/肘部法则）
  5.5 聚类结果分析
6 问题三：多分类器对比与类别识别
  6.1 问题分析
```

## 七、范文级别的论证节奏模板

每问内部遵循"总-分-总"结构：

```
5.X 问题X的XX模型

【总：1段问题分析】
  分析这一问的核心是什么、难点在哪里、为什么选这个方法
  （约150-200字）

【分：建模+求解】
  5.X.1 模型建立
    符号定义 → 目标函数 → 约束条件 → 推导过程
    公式编号规范，关键步骤配文字解释
  
  5.X.2 求解算法
    具体方法 → 参数设置 → 工具/库 → 收敛条件
    技术细节拉满，无黑箱表述
  
  5.X.3 结果与分析
    结果表格 + 结果图 + 详细解读
    分析结果的含义、规律、是否符合预期

【总：小结/检验】
  5.X.4 结果检验/方法对比
    合理性验证 + 误差分析 + （可选）多方法对比
    约100-150字
```

这个节奏和国奖论文完全对齐：先引入问题→再建模型→再求解→再分析结果→最后验证。逻辑清晰、层层深入。
