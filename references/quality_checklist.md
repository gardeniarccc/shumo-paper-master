# 质量自检清单

> 完成论文后，逐项对照检查。未通过项必须补充或修改。

---

## 一、摘要检查（决定档次的核心）

- [ ] 字数在300-500字之间
- [ ] 第一段：背景与问题（1-2句）
- [ ] 第二段：总体思路（1句）
- [ ] 第三段：每个子问题都有**明确方法 + 核心量化结果**
- [ ] 第四段：有创新点/亮点说明（1-2句）
- [ ] 关键词3-5个，精准对应方法与问题领域
- [ ] 没有空话套话（"深入研究""效果良好"等）
- [ ] 读完摘要即可知道全文做了什么、用了什么、得到了什么

---

## 二、结构完整性检查

- [ ] 摘要（中英文，如果是国赛只需中文）
- [ ] 问题重述
- [ ] 模型假设（5-8条）
- [ ] 符号说明（三线表格式）
- [ ] 数据预处理与描述性分析
- [ ] 模型建立与求解（每问独立成节）
- [ ] 结果检验与误差分析
- [ ] 灵敏度分析（2-3个参数）
- [ ] 模型评价与推广（优点+缺点+推广）
- [ ] 参考文献
- [ ] 附录（核心代码）

---

## 三、模型规范检查

### 每个模型都要问：

- [ ] 有没有选型理由（为什么用这个方法？）
- [ ] 有没有完整的数学表达式（目标函数+约束条件）
- [ ] 公式有没有编号（按章节编号，如式(3-1)）
- [ ] 所有符号有没有在符号说明中定义
- [ ] 符号前后是否一致（同一符号不表示不同含义）
- [ ] 推导步骤是否清晰，有没有跳步
- [ ] 求解算法的参数是否明确（迭代次数、种群规模等）
- [ ] 求解工具/库是否说明
- [ ] 结果是否有量化指标
- [ ] 结果是否有分析（不只是甩数字）

### 数据处理检查

- [ ] 数据来源是否说明
- [ ] 缺失值处理：方法+依据+比例
- [ ] 异常值处理：检测方法+判定标准+依据
- [ ] 标准化/归一化：方法+依据
- [ ] 有没有描述性统计（均值、标准差等）
- [ ] 有没有描述性统计图表（直方图/箱线图/热力图）
- [ ] 每个处理步骤有没有说明依据

---

## 四、图表规范检查

### 通用

- [ ] 所有图、表都有编号（按章节编号，不重不漏）
- [ ] 所有图、表都有标题（图题在下方，表题在上方）
- [ ] 正文中第一次提到的位置附近有对应的图表
- [ ] 图片清晰（300dpi以上）

### 图

- [ ] X轴Y轴有标签（变量名+单位）
- [ ] 有图例（多条线/多组数据时）
- [ ] 刻度清晰可读
- [ ] 配色专业（不花哨、对比清晰）
- [ ] 没有3D效果等花哨装饰

### 表

- [ ] 统一三线表格式（顶线、表头线、底线）
- [ ] 没有竖线
- [ ] 数据小数位统一
- [ ] 单位标注清楚

---

## 五、结果检验与灵敏度分析检查

### 结果检验

- [ ] 有没有合理性验证（结果是否符合常识/业务逻辑）
- [ ] 有没有误差量化（MAE/RMSE/MAPE等）
- [ ] 有没有误差来源分析
- [ ] （加分项）有没有两种方法的结果对比

### 灵敏度分析

- [ ] 选取了2-3个核心参数
- [ ] 参数变化范围合理（通常±20%）
- [ ] 有灵敏度分析图（龙卷风图/折线图）
- [ ] 有影响程度排序
- [ ] 有结论（模型鲁棒性如何）

---

## 六、格式规范检查

### 公式

- [ ] 所有公式按章节编号（式(3-1)、式(3-2)...）
- [ ] 公式中符号与符号说明一致
- [ ] 重要公式单独成行居中
- [ ] 推导过程有文字解释

### 参考文献

- [ ] 数量8-15篇
- [ ] 严格GB/T 7714格式
- [ ] 正文有引用标注（[1][2]...）
- [ ] 引用序号与列表一一对应
- [ ] 中英文文献结合
- [ ] 格式统一（作者、标题、期刊、年份、卷期、页码）

### 符号与术语

- [ ] 符号全局统一
- [ ] 术语前后一致
- [ ] 变量字体规范（向量粗体、矩阵大写、标量斜体）
- [ ] 下标含义统一

### 排版

- [ ] 章节编号正确
- [ ] 页码正确
- [ ] 没有整页只有图的情况（图题 + 至少几行文字分析）
- [ ] 没有大面积空白

---

## 七、文风与反AI检查

### AI套话排查（发现一个改一个）

- [ ] "综上所述" → 直接说结论
- [ ] "总而言之" → 直接说结论
- [ ] "值得一提的是" → 删掉，直接讲内容
- [ ] "不难看出" → 删掉，给出依据
- [ ] "显而易见" → 删掉，给出依据
- [ ] "效果显著" → 具体说效果提升了多少
- [ ] "具有重要意义" → 具体说有什么意义
- [ ] "深入研究" → 具体说研究了什么
- [ ] "全面分析" → 具体分析了什么

### 其他文风问题

- [ ] 有没有口语化表述
- [ ] 有没有第一/第二人称（"我们"可以有，"你/我"不行）
- [ ] 句子是不是长短结合（不是清一色长句）
- [ ] 每句话有没有明确的信息点（不是凑字数的废话）

---

## 八、致命红线检查（触碰直接降档）

- [ ] ❌ 摘要没有量化结果
- [ ] ❌ 数据来源不明、处理黑箱
- [ ] ❌ 公式无编号、符号无定义
- [ ] ❌ 图表无编号无标题、坐标轴无标注
- [ ] ❌ 编造数据/算法/结果
- [ ] ❌ 前后内容矛盾
- [ ] ❌ 参考文献格式混乱且正文无引用
- [ ] ❌ 模型推导完全跳步
- [ ] ❌ 没有灵敏度分析
- [ ] ❌ 结果只展示不分析

---

## 九、篇幅检查

国一论文篇幅参考（C题3-4问）：

| 部分 | 占比 | 约页数（正文25页计） |
|------|------|---------------------|
| 摘要 | 1-2% | 半页 |
| 问题重述 | 2% | 半页 |
| 假设与符号 | 3-4% | 1页 |
| 数据处理 | 8-10% | 2-2.5页 |
| 模型建立与求解 | 50-60% | 12-15页 |
| 灵敏度分析 | 5-8% | 1-2页 |
| 结果检验 | 5-8% | 1-2页 |
| 模型评价与推广 | 3-5% | 约1页 |
| 参考文献 | 2-3% | 半页-1页 |
| 附录 | 另计 | 按需 |

**检查**：
- [ ] 正文总页数在合理范围（22-35页）
- [ ] 各部分比例大致合理
- [ ] 模型部分是主体（占一半以上）
- [ ] 数据处理部分不喧宾夺主

---

## 十、最终提交前10分钟快速检查清单

时间紧张时，至少确保以下10项没有问题：

1. [ ] 摘要里每个问题都有方法+数字
2. [ ] 所有公式都有编号
3. [ ] 所有图都有编号和标题
4. [ ] 所有表都是三线表且有编号
5. [ ] 参考文献格式正确且正文有引用
6. [ ] 灵敏度分析至少做了2个参数
7. [ ] 模型优缺点都有（不只是优点）
8. [ ] 没有明显的AI套话
9. [ ] 符号前后一致，没有未定义的符号
10. [ ] 没有错别字和格式混乱的页面
